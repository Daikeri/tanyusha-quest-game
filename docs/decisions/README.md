# Architecture Decisions (ADR-lite)

Каждое решение хранится отдельным файлом в этой директории.

## Формат имени

`YYYYMMDD-NN-short-title.md`

Пример: `20260424-03-chunking-fallback-chonkie-token.md`

## Шаблон

Используйте `template.md`:

1. Context
2. Options Considered
3. Decision
4. Consequences
5. Revisit Trigger

## Правила

- Не переписывать старое решение молча.
- При смене решения создавать новый ADR и ссылаться на предыдущий.
- Решения должны быть проверяемыми и связанными с фактическими изменениями.
- Хронология определяется парой (`YYYYMMDD`, `NN`), где `NN` — двухзначный порядковый номер в пределах одной даты.
- `NN` должен быть уникален в пределах одной даты.
