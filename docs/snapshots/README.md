# Регламент snapshot

Канонический регламент перенесён без изменения правил в [docs/common/iteration-snapshots.md](../common/iteration-snapshots.md), по пути, указанному в `AGENTS.md`.

Результаты итераций находятся в корневом `snapshot/`, журнал — в `snapshot/INDEX.md`. Этот каталог сохранён как указатель для прежних ссылок.
