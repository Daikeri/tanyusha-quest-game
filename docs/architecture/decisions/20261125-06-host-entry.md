# ADR-lite. Вход ведущего и подготовка комнаты

Decision ID: 20261125-06
Date: 2026-11-25
Status: Accepted

## Context

При сетевой игре ведущий показывает участникам QR до запуска сюжета. Решение дополняет [ADR о сетевом голосовании](20261125-04-firebase-voting.md).

## Options Considered

- Вход и ручное создание комнаты из панели ведущего.
- Отдельная форма входа с автоматической подготовкой комнаты.

## Decision

Корневая страница открывает форму входа ведущего. После проверки аккаунта и подтверждения записи комнаты в Firebase стартовый экран показывает QR. Подтверждённый перезапуск закрывает старую комнату и повторяет подготовку. Локальная репетиция доступна с экрана входа.

## Consequences

Ведущий получает готовую ссылку перед запуском сюжета. Участники повторного прохождения подключаются по новому QR. После ошибки при подготовке ведущий может повторить подключение.

## Revisit Trigger

Восстановление прохождения ведущего или сохранение состава участников между прохождениями.
