# ADR-lite: публикация игры на GitHub Pages

Decision ID: 20261125-05
Date: 2026-11-25
Status: Accepted

## Context

QR должен открываться на телефоне, а адрес `localhost` доступен только на устройстве, которое его открывает. Проект развивает решение о работе без сборки `20261125-01-browser-runtime.md`.

## Options Considered

- Публикация корня репозитория из ветки.
- GitHub Actions с явным списком файлов сайта.

## Decision

Публиковать страницы, стили, модули и лицензию с помощью GitHub Actions. Ссылку участника строить относительно страницы ведущего, сохраняя подкаталог репозитория. Для запуска с `localhost`, `127.*` и `[::1]` использовать адрес `https://daikeri.github.io/tanyusha-quest-game/`.

## Consequences

QR одинаково работает при открытии ведущим опубликованной игры и при запуске с loopback после публикации страницы участника. Правила Firebase публикуются отдельно.

## Revisit Trigger

Переезд на другой домен, в другой репозиторий или изменение состава публикуемых файлов.
