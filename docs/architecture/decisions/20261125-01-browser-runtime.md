# ADR-lite: браузерный runtime без сборки

Decision ID: 20261125-01
Date: 2026-11-25
Status: Accepted
Related Snapshot: `snapshot/20261125_1627__implement-prologue`

## Context

Нужна локальная первая реализация сюжетной игры на чистых web-технологиях. Пользователь выбрал HTML/CSS/JavaScript без сборщика и простой pixel art.

## Options Considered

- Браузерные ES-модули, Canvas, DOM и Web Audio.
- TypeScript со сборкой.
- UI-фреймворк или готовый игровой движок.

## Decision

Использовать ES-модули без runtime-зависимостей. Canvas рисует мир, DOM — текст и управление. Контракты описать JSDoc. Ресурсы первой итерации создавать процедурно, без внешних загрузок.

## Consequences

Достаточно сервера статических файлов. Отсутствуют установка npm-пакетов и компиляция. Нет автоматической проверки типов компилятором; ссылки сценария проверяет runtime-валидатор. Замена графики не требует переписывать сюжетные команды.

## Revisit Trigger

Существенный рост команды и сценарных контрактов либо явный запрос на строгую проверку типов и сборку.
