# Architecture Decisions

Канонический каталог ADR-lite согласно `AGENTS.md`. Имена: `YYYYMMDD-NN-short-title.md`. Решения не переписываются молча: при изменении создаётся новая запись со ссылкой на прежнюю.

Одна запись — один архитектурный выбор. Разделы: Context, Options Considered, Decision, Consequences, Revisit Trigger. Состояние системы описывается в соседнем `current-state.md`.
