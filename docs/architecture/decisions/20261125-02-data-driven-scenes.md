# ADR-lite: сцены как последовательности команд

Decision ID: 20261125-02
Date: 2026-11-25
Status: Accepted
Related Snapshot: `snapshot/20261125_1627__implement-prologue`

## Context

Последующие сцены повторяют диалоги, перемещения, ожидания и развилки. Нужна переиспользуемость без копирования исполнения для каждой сцены.

## Options Considered

- Отдельные классы и обработчики каждой сцены.
- Данные команд, общий проигрыватель и адаптеры исполнения.

## Decision

SceneRunner исполняет описания Scene/Command. Runtime отделяет графику и интерфейс от управления потоком. Время централизовано в GameClock; каждый запуск использует AbortController. Параллельная группа является барьером завершения дочерних действий. Ветви сходятся через общую ссылку на сцену.

## Consequences

Новые сцены на существующих механиках требуют только данных. Можно тестировать ход сюжета без Canvas. Новая механика требует расширения контракта и обработчика; автор отвечает за отсутствие конфликтующих параллельных анимаций одного объекта.

## Revisit Trigger

Потребность в редакторе сценариев, загрузке внешнего формата или существенно более сложном взаимодействии параллельных сюжетных потоков.
