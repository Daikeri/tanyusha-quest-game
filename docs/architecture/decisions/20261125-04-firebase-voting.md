# ADR-lite: сетевое голосование в Firebase

Decision ID: 20261125-04
Date: 2026-11-25
Status: Accepted

## Context

Участники голосуют с телефонов, а ведущий управляет постановкой на общем экране. Решение развивает `20261125-03-local-voting.md`.

## Options Considered

- Firebase Realtime Database и Firebase Authentication.
- Supabase Realtime и PostgreSQL.
- Собственный сервер сессий.

## Decision

Добавить FirebaseVoting рядом с LocalVoting. Firebase хранит комнаты, вопросы и голоса. Ведущий входит под выделенной учётной записью, телефоны входят анонимно. Правила базы проверяют доступ и срок голосования. Ведущий закрывает вопрос транзакцией и публикует итог при сюжетном продолжении.

## Consequences

Обе страницы используют один Firebase-проект. Сетевая сессия переживает обновление страницы участника. Сценарный прогресс остаётся в памяти браузера ведущего.

## Revisit Trigger

Восстановление постановки после перезагрузки ведущего или необходимость индивидуальных приглашений.
