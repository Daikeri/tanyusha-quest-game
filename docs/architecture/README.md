# Архитектурная документация

Этот раздел фиксирует архитектуру проекта в формате, удобном для итеративной агентной разработки.

## Структура

- `core.md` — стабильные архитектурные инварианты.
- `current-state.md` — фактическое текущее состояние системы.
- `decisions/` — ADR-lite решения (одно решение = один файл).

## Принципы ведения

- Код — источник истины. Документация должна соответствовать коду.
- Решения фиксируются отдельно от состояния.
- Стабильные правила не смешиваются с временными деталями.

## Правила обновления

- В `Code Mode`:
  - обновлять `current-state.md` по факту изменений;
  - фиксировать архитектурные выборы в `decisions/*.md`;
  - обновлять `core.md`, если изменился стабильный инвариант.
- В `Spec Mode` и `Other Mode`:
  - допустимы предложения и черновики;
  - фактическое состояние не помечать изменённым без изменений в коде.

## Bootstrap для новой сессии

Агент в начале сессии должен прочитать:

1. `AGENTS.md`
2. `docs/common/iteration-snapshots.md`
3. `docs/architecture/core.md`
4. `docs/architecture/current-state.md`
5. свежие решения из `docs/architecture/decisions/`
