# Архитектурные инварианты

- Игра — управляемая ведущим сюжетная постановка; свободного управления персонажем нет.
- Браузерный runtime использует стандартные HTML/CSS/JavaScript API. Runtime-зависимостей и обязательного этапа сборки нет.
- Сценарий — данные с командами, различаемыми по `type`. Сцены на существующих механиках не требуют отдельного класса или изменений проигрывателя.
- Исполнитель сценария отделён от Canvas, DOM, аудио и источника результата интерактива. Он обращается к runtime через `sceneChanged`, `execute`, `error`.
- Общие часы определяют время сценарных анимаций, печати текста и голосования. Пауза останавливает их; незавершённая работа привязана к `AbortSignal` текущего запуска.
- Результат интерактива и разрешение продолжить постановку — отдельные этапы. Выбор не должен самостоятельно пролистывать последующую реплику.
- Факты прохождения хранятся в `GameState`; визуальные компоненты не определяют сюжетную ветку.
- Код является источником истины. Текущий объём функций описывается отдельно от инвариантов.
