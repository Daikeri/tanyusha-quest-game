# Iteration Snapshot

Date: 2026-11-25
Time: 16:27
Title: implement-prologue

## Goal

Реализовать согласованный план первых сцен «Я.МОЛОД — доступ открыт?» на чистых web-технологиях с переиспользуемым проигрывателем. Режим: Code Mode. Материалы — `ref/general.txt` и `ref/scene_0_3.pdf`, включая переписку на изображении страницы 9.

## What Was Done

- Создано приложение HTML/CSS/JavaScript без сборки и runtime-зависимостей. Canvas используется для мира, DOM — для текста и управления.
- Реализованы заставка и сцены 01–03: аудитория, Никита и Соня, приглашение, имитация выбора, обе ветки, комната, шесть сообщений переписки и путь к молодёжному центру. Ветки сходятся в терминальной точке `scene04` без реализации следующей сцены.
- Выделены типизированные через JSDoc команды, SceneRunner, GameClock, проверка ссылок, общий рендерер персонажей, представления и аудиоменеджер. Сценарий отделён от исполнения; движение по маршрутам, параллельные действия и отмена переиспользуются.
- Сделаны панель ведущего, управление репликами пробелом, раскрытие печати, пауза, подтверждённый перезапуск, звук и полноэкранный режим. Переключение вкладки ставит активную историю на паузу.
- LocalVoting ждёт 30 секунд или досрочного завершения; без заданной ветки продолжает ожидание. После фиксации результата ждёт отдельного пробела, затем показывает реплику один раз.
- Добавлены простой pixel art, портреты, локации, афиша, вложение переписки, процедурная музыка и эффекты. Текст переписки увеличен после визуальной проверки.
- Подготовлены инструкция запуска, описание авторинга сцен, архитектурные документы и три ADR.
- Регламент snapshot перенесён из существующего `docs/snapshots/README.md` в требуемый `docs/common/iteration-snapshots.md` без изменения содержимого правил; совпадение проверено по исходнику Git. Перед коммитом удалены хвостовые пробелы и пустые строки в конце перенесённого файла и `.gitignore`. Старые каталоги документации оставлены с указателями.
- Прошли 13 автоматических проверок движка и браузерное прохождение обеих веток в Microsoft Edge. Проверены пауза и фиксация результата, ожидание без выбора, переписка, перезапуск/отмена, звук, полноэкранный режим, размеры 1280×720, 1920×1080 и 390×844. Ошибок JavaScript нет.

## What Did NOT Work

- В репозитории изначально отсутствовали архитектурные документы и регламент по путям из `AGENTS.md`. Найден существующий регламент в другом каталоге, структура приведена к указанным путям.
- Первый браузерный QA-прогон нажимал пробел при фокусе на кнопке паузы: браузер корректно активировал кнопку, и тест ошибочно оставлял игру на паузе. Тест исправлен: проверка игрового пробела выполняется с фокусом на игровом поле. Последующие прогоны прошли.
- При подготовке коротких указателей документации попытка delete/add одного пути была отклонена инструментом; последующая передача русского текста через стандартный канал PowerShell/Python потеряла кодировку. Файлы перезаписаны штатным `Set-Content -Encoding UTF8` и прочитаны повторно для проверки.
- Node/npm отсутствуют в PATH; для приложения они не понадобились. Проверки движка выполняются в браузере, автоматизация — установленными Python Playwright и Edge.
- Не проверены физический проектор и другие браузеры. Звуковые API проверены на ошибки, субъективное прослушивание не проводилось.
